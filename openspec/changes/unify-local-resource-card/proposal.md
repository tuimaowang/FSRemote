## Why

当前本机页把实时资源监控和静态系统信息拆成上下两个卡片，信息重复且不符合用户希望的纵向硬件概览。页面还缺少内存条数量、容量组合、插槽、类型和速率等实际排查硬件时更有价值的信息。

## What Changes

- 将本机页的 CPU、GPU、内存和磁盘合并为一个连续的大卡片，不再绘制独立“本机系统信息”卡片。
- 删除本机页中的电脑名称、Windows 版本、IPv4、MAC、子网掩码和默认网关展示。
- CPU 行保留实时占用、型号、逻辑处理器数量和架构。
- GPU 行保留实时占用；能够读取时显示 GPU 型号和专用显存，读取不到时保持明确占位。
- 内存行显示实时占用、已用/总量、内存条数量与容量组合、已使用/总插槽、内存类型和速率。
- 磁盘区域按文件资源管理器风格逐盘显示容量条、已用、总量和可用容量，并继续支持任意数量的本地盘符。

## Capabilities

### New Capabilities

- `local-resource-card`: 定义本机页单卡片资源布局、硬件摘要字段、内存模块信息和磁盘容量条的显示及降级行为。

### Modified Capabilities

无。

## Impact

- 扩展 `LocalSystemInfoService` 的只读硬件采集结构和 Windows 查询逻辑。
- 调整 `DeviceGrid` 本机页的手绘布局、高度计算与文字裁切。
- 对硬件信息格式化、字段降级和旧本机信息移除执行静态检查；不修改设备目录、网络协议、远控流程或持久化配置。
