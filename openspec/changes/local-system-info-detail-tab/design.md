## Context

`DeviceGrid` 的详情页由手绘页签和页面内容组成，本次调整后默认页签为本机，配置页继续复用同一内容区域。项目已有 `DeviceInfoService` 提供电脑名和主要 IPv4 网卡信息，但没有操作系统、CPU 型号、内存容量、系统盘占用或 CPU 使用率采样能力。

## Goals / Non-Goals

**Goals:**

- 在脚本左侧增加与现有页签一致的“本机”入口。
- 设备详情区首次显示时默认进入本机页，不再默认打开脚本页。
- 用独立服务统一采集本机静态系统信息及 CPU、GPU、内存使用率。
- 进入本机页时每秒更新 CPU、GPU、内存占用，离开页面立即停止周期刷新。
- 三类资源新样本通过独立短时缓动更新数字和环形指示器，避免一帧闪现到目标值。
- 使用只读存储查询展示系统盘盘符、已用容量、总容量和占用百分比。
- 保持系统查询只读，不影响远控、设备目录或网络协议。

**Non-Goals:**

- 不实现任务管理器、进程列表、温度、风扇、GPU 温度/显存/频率或多磁盘实时监控。
- 不把本机性能数据写入配置、设备 JSON 或实时广播协议。
- 不改变现有设置页“本机信息”卡片的行为。

## Decisions

### 独立 LocalSystemInfoService

新增独立服务返回电脑名、操作系统、CPU 型号、CPU 架构、逻辑处理器数、物理内存容量、系统盘容量和现有 `DeviceInfoService` 网络信息。Windows 使用 PDH、`GlobalMemoryStatusEx` 和只读注册表查询；系统盘通过 `QStorageInfo::root()` 只读获取；其它平台返回 Qt 可提供的系统信息和不可用占位。

### CPU 使用率采用任务管理器的 Processor Utility 口径

Windows 使用英文 PDH 计数器 `\\Processor Information(_Total)\\% Processor Utility`。该计数器在处理器忙碌时间基础上考虑当前频率相对标称频率的变化，比 `GetSystemTimes` 的传统忙碌时间更接近 Windows 10 任务管理器的 CPU 百分比。第一次采集只建立 PDH 基线，页面显示“采样中”，后续值按任务管理器界面限制在 0–100；计数器不可用时显示占位，不伪造为 0%。

采样值和显示值分离：采样器仍每秒返回一次整数结果，`QVariantAnimation` 使用当前画面值作为起点，在约 320ms 内缓动到新结果。环形指示器使用小数显示值计算圆弧角度，百分比数字对同一显示值取整，因此二者始终同步增减。切页、重新建立采样基线或退出程序时停止动画。

### GPU 与内存使用率只读采样

Windows GPU 使用 `\\GPU Engine(*)\\Utilization Percentage` 英文 PDH 通配符计数器读取全部进程引擎实例。采样器从实例名解析 `luid + phys + eng` 作为物理引擎标识，先汇总同一物理引擎上不同进程和上下文的占用，再从全部物理引擎中取最繁忙值并限制到 0–100。该聚合方式对应任务管理器基于 WDDM 调度器统计整体 GPU 占用的口径，避免误把单个进程实例的最大值当作整机 GPU 使用率。首次 PDH 采集只建立基线，计数器不可用时 GPU 圆环显示占位，不阻止 CPU 和内存。

物理内存使用率通过 `GlobalMemoryStatusEx` 的当前负载百分比读取，无需相邻样本。CPU、GPU、内存各自拥有独立 `QVariantAnimation`，共用一秒采样定时器和 320ms 缓动曲线。

### 只在本机页激活定时器

`DeviceGrid` 创建一个 1000ms 定时器，但只有进入本机页时启动。该定时器统一读取 CPU、GPU、内存并分别驱动三枚圆环。切换到脚本、配置、设置或其它页面时停止，并关闭 GPU 查询句柄，避免主界面长期产生无意义系统调用和重绘。

默认本机页的静态信息通过零延迟事件队列回调读取，避免在 `DeviceGrid` 构造函数尚未完成时同步调用网卡和系统查询。设备列表为空且程序进入新增设备设置页时不读取、不启动采样。

### 页面继续使用手绘详情布局

本机页属于现有详情导航，使用与脚本/配置相同的内容边界。顶部按 CPU、GPU、内存均分为三列，每列左侧显示标签和摘要、右侧显示独立环形占用，并用底部整行显示系统盘占用。下方继续用两列信息卡展示静态系统与网络字段，不新增可交互编辑控件。

## Risks / Trade-offs

- [第一次 CPU 采样没有时间差] → 显示“采样中”，一秒后再展示有效百分比。
- [CPU 型号注册表字段缺失] → 回退到 CPU 架构文本，不阻止其它系统信息显示。
- [系统信息查询失败] → 单个字段显示 `--`，页面和定时器继续正常工作。
- [系统盘信息不可用] → 系统盘占用显示 `--`，不阻止 CPU 和其它系统字段显示。
- [页面切换后定时器残留] → 定时回调再次校验当前页签，不在本机页时主动停止。
- [GPU 计数器不存在或驱动未暴露实例] → GPU 圆环显示占位，每秒允许重新采样，CPU 和内存继续正常更新。
- [与任务管理器瞬时读数存在轻微偏差] → 使用相同系统计数器和聚合口径；由于两个程序的采样时刻及本机页 320ms 显示动画不同，不承诺每一帧完全相同，但稳定负载下应保持一致趋势和接近数值。

## Migration Plan

新增服务文件、CMake 源列表和详情页签代码即可，无数据迁移。回滚时删除本机页签、定时器和服务源文件，不影响已有设备与设置数据。
