## Why

主控窗口的设备详情区目前只关注远端设备，用户无法在同一区域快速查看本机系统环境和当前 CPU 压力。新增本机页签可以在远控操作前直接确认控制端的系统与资源状态。

## What Changes

- 在设备详情页“脚本”左侧新增“本机”页签，并在设备详情区首次显示时默认选中本机页。
- 本机页展示电脑名称、操作系统、CPU 型号、逻辑处理器数量、内存容量、系统盘占用以及主要网络信息。
- 本机页按 CPU、GPU、内存三列实时显示占用百分比和环形进度指示器，新样本到达时数字与圆环平滑过渡，进入页面时启动采样，离开页面后停止刷新。
- 新增独立本机系统信息与资源使用率采样服务，CPU 使用 Windows `% Processor Utility` 口径，GPU 按物理引擎汇总全部进程实例后取最繁忙引擎，尽量与任务管理器保持一致，并避免在 `paintEvent` 中调用系统查询接口。

## Capabilities

### New Capabilities
- `local-system-info-detail`: 定义本机详情页签、静态系统信息展示和 CPU 占用周期刷新行为。

### Modified Capabilities

无。

## Impact

- 新增本机系统信息服务源文件，并加入 FSRemote 主程序构建源列表。
- 扩展 `DeviceGrid` 的设备详情页签、绘制、点击和定时刷新状态。
- Windows 使用只读系统 API 和 PDH 性能计数器获取 CPU、GPU、内存和系统信息，不修改配置、不访问网络、不改变远控协议或设备数据。
- Windows GPU 占用通过 PDH 的 GPU Engine 性能计数器只读采样，主程序增加系统库链接，不引入额外运行时组件。
- 使用 Qt 只读存储信息查询系统盘盘符、已用容量、总容量和占用百分比。
