## Why

设备数量和分组增多后，用户仅记得设备名称、分组、MAC 或 IP 的部分内容时，很难从左侧列表快速定位目标。需要在主界面详情区提供随时可用的模糊查找页，把零散记忆转换为候选设备并可直接定位。

## What Changes

- 在设备详情页“配置”右侧新增“查找”页签，点击页签或按 `Ctrl+F` 切换到嵌入式查找页。
- 提供设备名、组名、MAC、四段式 IP 输入区域和候选设备列表，输入变化时实时筛选，不再显示重复的搜索按钮。
- 支持名称、分组和 MAC 的不区分大小写包含匹配；IP 支持按对应网段填写，也支持只按顺序输入记得的若干网段片段。
- IP 输入框按回车将焦点移动到下一段，最后一段回车主动刷新当前筛选结果。
- 候选只有一台或用户选择某一行时，自动把该设备的完整信息回填到全部输入框。
- 双击候选设备后展开所属分组、选中目标设备并返回配置页显示该设备详情。

## Capabilities

### New Capabilities
- `device-fuzzy-search`: 定义 Ctrl+F 搜索入口、多字段模糊匹配、四段 IP 输入、候选回填和主窗口定位行为。

### Modified Capabilities

无。

## Impact

- 新增独立 `DeviceSearchPanel` UI 模块，并在 `DeviceGrid` 中接入详情页签、快捷键、设备快照和定位回调。
- 更新 CMake 主程序源文件列表，不改变设备 JSON、同步协议、远控协议、端口或 DLL API。
- 搜索只读取当前内存中的设备目录，不访问网络、不修改设备数据。
