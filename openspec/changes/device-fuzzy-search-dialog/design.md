## Context

`DeviceGrid` 当前直接持有主窗口大量绘制和交互逻辑，设备数据的权威来源是 `DeviceCatalog`，展示层通过只读设备数组和稳定设备 ID 使用。新增搜索功能包含多个真实输入控件、结果表格和匹配状态，不适合继续以内嵌手绘区域堆入 `DeviceGrid.cpp`。

## Goals / Non-Goals

**Goals:**

- 用独立嵌入式面板承载搜索控件和模糊匹配逻辑，并与配置页复用详情内容区域。
- 支持用户只记得任意部分设备信息时快速收窄候选。
- IP 同时支持明确位置和按顺序记忆的片段，满足只输入 `2`、`9` 查找 `192.168.2.9`。
- 用稳定设备 ID 把选中结果交回主窗口，定位不依赖可能变化的数组下标。

**Non-Goals:**

- 不修改、保存或同步设备数据。
- 不访问网络验证搜索结果在线状态。
- 不改变现有远控快捷键、协议、端口或设备列表排序规则。

## Decisions

### 独立 DeviceSearchPanel

新增独立 `QWidget` 面板和只读 `DeviceSearchItem` 快照结构。`DeviceGrid` 切换到查找页时从当前目录生成快照，面板自行过滤、回填和展示。这样搜索逻辑仍与主窗口复杂绘制状态隔离，同时不再创建割裂主界面的模态弹窗。

### 查找页签复用设备详情导航

设备详情页签扩展为“脚本 / 配置 / 查找”，查找位于配置右侧，内容区域与配置页使用同一边界。点击页签切换页面；双击搜索结果后按稳定设备 ID 定位，并切回配置页展示目标设备。

### Ctrl+F 使用窗口子控件范围快捷键

在 `DeviceGrid` 上创建 `QShortcut(QKeySequence::Find)`，上下文设为 `WidgetWithChildrenShortcut`。因此焦点位于主窗口输入框时也能直接切换到查找页并聚焦首个输入框，而远控窗口获得焦点时不会误触发主控搜索。

### 多字段条件使用 AND、字段内部使用模糊包含

设备名、组名和 MAC 均采用不区分大小写的包含匹配，非空字段之间同时满足。IP 拆为四段：先尝试非空框按固定位置匹配；同时把非空片段作为有序序列在真实四段 IP 中查找。两者任一成功即视为 IP 匹配，兼容精确网段输入和零散顺序记忆。

### 唯一候选与手动选择回填

输入变化实时刷新，不再提供功能重复的搜索按钮；最后一段 IP 回车仍可主动刷新。结果只有一台时自动回填全部字段；多个候选时单击行回填该设备但保留候选列表。双击行通过回调返回稳定设备 ID，主窗口展开目标分组、选中设备并切换详情。

## Risks / Trade-offs

- [有序 IP 片段可能产生较多候选] → 结果表展示完整名称、分组、IP 和 MAC，用户可继续追加条件或点击目标行。
- [回填字段触发递归搜索] → 使用信号阻断和内部回填标志，回填只更新显示而不重复过滤。
- [唯一结果反复覆盖用户编辑] → 记录最近一次已回填的稳定设备 ID；同一唯一结果只自动回填一次，候选回到零个或多个后才重新开放自动回填。
- [查找期间设备目录发生变化] → 每次进入查找页都会读取最新目录，定位时主窗口按稳定 ID 重新解析并安全忽略已删除设备。

## Migration Plan

新增源文件并加入主程序目标即可，无配置迁移。移除功能时删除快捷键接入和查找面板源文件，不影响设备目录数据。

### Temporary staging gate

按当前产品安排，查找面板实现和构建源暂时保留，但 `Ctrl+F` 注册、面板创建、页签绘制、悬停命中和点击入口通过就近注释或 `#if 0` 门禁停用。后续启用时只恢复这些入口，不需要重新实现搜索、回填或定位逻辑。
